# B_raw基準・異種モデルアンサンブルV1 — 実測最終報告（2026-10-31）

## 結論：点推定では改善したが、one-SE基準に達せずB_rawを維持

**既存の最良モデルB_raw（F3入力・400本XGBoost）を市場logit補正の主軸として、LightGBM・CatBoostとの固定平均および2023年OOFだけで学習する正則化付きアンサンブルを実装・比較した。**

事前固定候補中の最良点Brierは **BLC_ridge_2023 = 0.135691548931475**。B_raw単体 **0.135721275824395** より低く、差は **0.000029726893**（相対改善 **0.02190%**）だった。ただし、開催日でクラスタ化したpaired SEは **0.000030991070** であり、**改善量／SE = 0.9592**。既存のpaired one-SE incumbent判定により **B_rawを維持**した。

点Brier最良という事実と採用基準不通過は区別する。**BLCを「改善実証済みの新最良モデル」と表現しない。** 見かけ上の差は小さく、2024年の結果は既に閲覧されている既知の開発期間であり、将来における市場超過を確証しない。

## 学習された補正重み・アンサンブル解釈

`p_i = sigmoid(logit(M0_i)+w_B f_B(i)+w_L f_L(i)+w_C f_C(i))`

で、`f_k=logit(p_k)-logit(M0)`。2023年のみのrace-macro Brier＋事前固定のL2正則化`0.0005∑(w-[1,0,0])²`をSLSQPで最適化。非負重み各[0,1.5]、合計<=2、最適化初期値[1,0,0]。市場のみ[0,0,0]もB_raw単体[1,0,0]も許容。

- **BLC ridge:** B_raw **1.065679**、LightGBM **0.116326**、CatBoost **0.052787**。
- **BL ridge:** B_raw **1.076967**、LightGBM **0.126227**、CatBoost **0**。

重みの合計は1に制限していない。したがって、改善は「他モデルとの平均効果」だけではなく**B_rawの市場logit補正を強める効果**も含む。単純な固定比率logit平均の多くはB_raw単体に負けた。

2024年の市場補正残差の相関はB_raw対LightGBM **0.972787**、B_raw対CatBoost **0.843420**。異種学習器だからといって既存の誤りを十分補うとは限らない。予測の相関だけでなく実際の同一レース損失差で判定している。

## 次の判断と限界

**結論：アンサンブル追加に対してB_raw単体を維持。** これは「改善が不可能」の意味ではない。今回の小幅な点改善は現行採用ゲート未通過であり、レースごとに条件付き重みを使うにはさらに新しい事前登録・独立の前向き情報が必要。

研究予測の元市場は過去の**最終オッズ**であり、発走10分前の同時刻オッズではない。2024年は既に結果を確認してきた開発期間であり、新規の未見検証ではない。2025/26も未見として扱わない。**本番は引き続きStage5市場のみ。** 発走10〜9分前の予測固定、最低1,000レース・60開催日・90日、途中の採否変更禁止を維持する。
