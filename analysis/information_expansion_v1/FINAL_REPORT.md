# Information Expansion V1 — 実データ比較・最終研究報告（2026-10-31 JST）

**実験結論：過去の最終単勝オッズを基準とする2023–2024年の開発評価では、同じ予測時点・同じ出走馬標本において、非線形XGBoostの市場logit補正モデルが既存のpaired one-SE基準を通過した。採用候補は X2。しかし現在の発走10分前モデルは更新しない。**

この研究はPR #31の後続であり、PR #31を改変・マージしない研究ブランチ `research/information-expansion-v1-20261031` で実施した。候補・モデルパラメータ・分割・評価基準は**新規スコアを見る前に** `docs/INFORMATION_EXPANSION_V1_SPEC.md` とコミット `1bab50544f9317f78e40ea1eab754450f8082f16` で固定した。データを確認した後の候補追加・ハイパーパラメータ再探索は行っていない。

## 2. 評価と候補

**2023年：2,887レース・32,051頭**（それまでの情報で学習）。
**2024年：2,844レース・31,225頭**（2023年までの情報で学習）。
合計 **5,731レース・63,276頭**。

芝 **2,651レース・28,926頭**、ダート **3,080レース・34,350頭**。1000～1400mが2,101レース、1401～2000mが3,170レース、2001～2600mが460レース。直線コースは既存Scope V3の対象外、実出走8頭以上、過去3走以上の馬のみ適格。市場確率は不適格馬を含む全出走馬の最終単勝オッズから復元する。候補ごとの評価行は完全一致。ソート後の評価行SHA256は `cb984b2553647d423e05742d0625988da3129dab3183f79b6fb84c74776a582f`。

- M0：市場のみ（単勝最終オッズ→Harville→2018年以降の各年に先立つ学習側だけでlogit校正）
- L0：既存の市場以外の特徴量を使った正則化付き線形logitオフセット。
- X0：L0と同じ既存情報を、固定パラメータの浅い非線形XGBoost logitオフセットに変更。
- X1：X0に3Fのレース内相対値・コーナー移動・過去馬体重・過去馬場・前走までの騎手・調教師の履歴を追加。
- X2：X1に過去相手関係を考慮したElo事前能力・前走対戦相手の能力情報を追加。

同じXGBoostモデルは120 trees, depth2, learning_rate 0.03, min_child_weight60, reg_lambda20, reg_alpha2, subsample/colsample 0.8、seed20261031に固定。`P = sigmoid(logit(P_market)+f(X))` はXGBoostの `base_margin` により実装しており、事後残差の単純な確率加算やclipではない。L0の学習側にのみ適用する欠損補完・カテゴリ符号化とXGBのnative欠損処理にはモデル族固有の差がある。

## 3. 全候補の同一標本スコア

| 候補 | race-macro Brier ↓ | race-macro log loss ↓ |
|---|---:|---:|
| M0：市場のみ | 0.137174575 | 0.424191221 |
| L0：従来情報の線形補正 | 0.137081133 | 0.423965119 |
| X0：従来情報の非線形補正 | 0.136823614 | 0.423184071 |
| X1：X0＋新履歴特徴量 | 0.136801060 | 0.423134987 |
| **X2：X1＋相手関係Elo** | **0.136769027** | **0.423012989** |

X2の市場M0に対する **Brier改善量 0.000405547**、開催日クラスタ化paired SE **0.000051873**。事前のpaired one-SE選択基準では市場only incumbentを維持できず、歴史最終オッズ領域の開発候補として**X2を選択**する。

この改善幅は相対的にBrierの約0.296%であり、**大幅な改善という表現は妥当でない**。本稿は2025や2026を未見検証と扱わず、歴史の開発スコアだけをもって将来精度・ROIを保証しない。

## 4. モデル変更と情報追加の寄与を分離した追加監査

`factor_attribution.csv` は保存済み予測のみで計算した**非選択的な要因診断**であり、登録済み候補・分割・ハイパーパラメータを変えていない。

| 追加変更 | race-macro Brier改善 | 同じ開催日でのpaired SE | 個別one-SE |
|---|---:|---:|---|
| 市場→既存情報の線形 | 0.000093441 | 0.000011786 | 通過 |
| 同じ既存情報で線形→非線形XGB | **0.000257519** | **0.000045728** | **通過** |
| X0→X1：未活用履歴の追加 | 0.000022553 | 0.000026301 | 不通過 |
| X1→X2：相手関係Eloの追加 | **0.000032033** | **0.000017552** | **通過** |
| 市場→X2：すべての変更 | **0.000405547** | **0.000051873** | **通過** |

**解釈：新履歴の追加効果は全標本では独立したone-SE基準を通過しない。最大の精度寄与は既存のレース・能力情報に対する非線形な市場補正だった。相手関係Eloは小さいが付加価値があった。**

芝とダートで違いがある。X0→X1の履歴追加は芝で改善 `+0.000084733`（SE `0.000044133`）する一方、ダートでは悪化 `-0.000030965`（SE `0.000031757`）。X1→X2のElo追加は2024年に改善 `+0.000072620`（SE `0.000022475`）したが2023年は微減 `-0.000007949`。これらは事後診断であって2024年だけを選んで採用したわけではない。

## 7. 本番移行判断と未実施

- **最終単勝オッズ**しかないため、現在の発走10分前T−10の市場に対する優位性は未立証。今回の開発予測を「発走前の本番精度」と書いてはならない。
- 対象馬のレース当日3F・通過・体重・馬場状態・着順は、入力特徴量へ一切使用していない。騎手・調教師も過去の最終観測者であり現行確定騎乗者ではない。
- G1の独立判定は行っていない。原データのクラス粒度が不足。
- 2025/2026の既知結果に基づく再選択なし。2023/24は歴史データの開発評価であり、将来の未見レースではない。
- **本番は Stage5 市場のみを継続**。有望なX2をT−10の真の同時刻市場で固定して新たな前向き研究とする場合も、既存仕様どおり **1,000レース・60開催日・90日間**、期間中モデル固定、発走10〜9分前の予測ロック、途中採否変更禁止を維持する。
- 新しい履歴フィードを本番で動かすには、本番予測時のJRAの過去完走情報・最新騎手等の信頼性、提供許諾、更新・復旧運用を別途構築・検証する必要がある。

**総括：PR #31で試し切れていなかった「予測モデル自体の非線形化」には歴史領域で明確な追加価値があり、相手の強さを調整するEloにも小幅な追加効果が認められた。一方、生のレース履歴追加を一括投入する効果は限定的。市場のみからの改善は測定されたが、将来の発走10分前予測を改善するかどうかは未判定。**
