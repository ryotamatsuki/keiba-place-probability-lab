## A：市場・芝ダート・相対能力を同一XGBoostへ追加

すべて固定`n_estimators=120,max_depth=2,eta=0.03`他のX2と同じパラメータ・同じ学習期間。F0は保存済みX2 42数値＋3カテゴリを**数値的に再現**し、既存M0と予測行を完全照合。F1は校正済み市場トップ3確率とlogit、surface追加。F2は既存Stage4の全頭leave-one-out相対能力5特徴量追加。F3は全出走馬の人気相対順位、単勝シェア・HHI、上位人気差と1番人気シェア追加。

| 候補 | 2023–24 race-macro Brier | log loss |
|---|---:|---:|
| **F0 元のX2を再現** | **0.136769027** | 0.423012989 |
| F1 市場信頼度・芝ダート | 0.136793565 | 0.422986637 |
| F2 F1＋相対能力5本 | 0.136789933 | 0.422974909 |
| F3 F2＋市場人気集中情報 | 0.136777640 | **0.422909451** |

**主指標Brierについて、入力追加単体ではF0 X2を上回らず。** F3はlog lossを改善したがBrierでの採用は否。F3とのpaired比較ではX2−F3 Brier`−0.0000086125`（SE`0.0000186223`）。**保存済みE5を2024年に上回る追加候補も無し。** `A_all_years_scores.csv`、`A_2024_E5_comparison.csv`、`A_2024_E5_paired.csv`、`A_2024_subgroups.csv`などへ保存。入力を増やすだけで改善を約束できないという否定結果。

## B：2021–23の内側時系列学習曲線でF3の木本数を選択

学習目的は従来どおりlogloss、評価と停止時点の選択だけ**race-macro Brier**。内側年ごと`60/120/240/400`木を固定候補にし、外側2023では2021–22、外側2024では2021–23のOOFで選択。結果はどちらも**400木**。同時に各外側年の補正幅係数αを、それ以前のinner OOFのみで、[0,1.5]の正則化Brier最小化で学習した。2023用α`0.84168868`、2024用α`0.94757310`。元E5 α`1.47825335`を新モデルへ流用していない。

| 候補（共通2024年2,844レース） | Brier ↓ | log loss ↓ |
|---|---:|---:|
| M0 市場のみ | 0.136376519 | 0.422136248 |
| 元X2 | 0.135939400 | 0.420907085 |
| E5 元X2強度調整（2023 fit） | 0.135838654 | 0.420632775 |
| **F3＋400木、raw** | **0.135721276** | **0.420229230** |
| F3＋400木＋学習側のα補正 | 0.135734702 | 0.420257804 |

**B raw はE5からBrier `0.000117378`改善（開催日単位paired SE `0.000064555`）し、事前のone-SE基準を通過。** 新モデルのα校正はrawよりむしろBrierを悪化。従って「E5係数1.4783が深さ不足の証拠」という理解は不要で、補正幅は新しいモデルと学習回数ごとに異なる。

学習曲線の各年race Brier/log loss、採用木本数・α・各fold日付は`B_inner_curves.csv`, `B_inner_oof_predictions.csv`, `B_outer_oof_predictions.csv`, `B_manifest.json`。参照GitHub Actions実行`41136225835` PASS。

## 結論・運用判定

今回最も明確だったのは、**新しい分岐特徴量だけの追加より、内側の年次時系列Brierで学習回数を選び直す方が有効だった**こと。これはユーザーの「まず学習曲線」という優先順位を支持する。新モデルの補正強度はE5の既存αを転用せず、rawと内側fit版を個別に比較した。

ただし2023/24は過去に結果を確認した開発期間で、**厳密な未見将来テストではない**。全て**最終オッズ領域**であって、実際のT−10オッズではない。モデルの本番採用は不可。Stage5市場のみ、予測ロックT−10..−9、1000レース／60開催日／90日間、期間中のモデル固定、途中判断変更禁止を維持。
