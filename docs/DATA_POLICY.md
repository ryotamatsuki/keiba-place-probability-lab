# Data Policy

## 1. 基本方針

このリポジトリは、公開情報を参照して作成した**出典情報・自作特徴量・自作予測・自作コード**を中心に保存します。
「公開されている」ことと「自由に再配布できる」ことは別なので、第三者コンテンツの再配布可否を個別に確認します。

## 2. 原則としてコミットしないもの

- JRAや第三者サイトの画像・スクリーンショット
- 即PAT / A-PAT等の投票画面、セッション情報、加入者番号等
- 第三者サイトのHTML丸ごと保存
- 利用条件で再配布が認められていないCSV・データベース
- 認証情報、Cookie、APIキー、個人情報

## 3. 保存するもの

`data/source_manifest.csv` に以下を記録します。

- source_id
- source_name
- source_url
- accessed_at
- as_of_time
- fields_used
- extraction_method
- redistribution_status
- terms_note
- notes

派生データは、元データの単純転載にならないよう、必要最小限の特徴量・集計値として保存します。

## 4. 取得時点

予測に使うデータには `as_of_time` を必須とします。発走後に確定した結果、最終オッズ、
事後記事等は「予測用特徴量」へ遡及混入させません。

最終オッズを使う場合は、事後ベンチマークとして明示的に別系列で扱います。

## 5. 自動取得

スクレイピングやAPI利用を実装する前に、対象サイトの利用規約・robots・技術的制約・再配布条件を確認します。
確認が済むまでは、URLと手入力・小規模な転記による検証を優先します。
