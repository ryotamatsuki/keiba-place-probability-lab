# Trio V2：実運用検証レポート（2026-10-31）

**判定：研究用Shadowのみ。既存F3の凍結済みモデル・11月1日のT-10予測は変更しない。実馬券への自動採用は NO_BET。**

## 0. 変更の対象と凍結保証

新規ブランチ `research/trio-v2-conditional-20261031` は、`research/tennosho-akiten-preoff-20261101` から分岐。既存 `models/tennosho_f3_20261101/f3_bundle.joblib`、`manifest.json`、天皇賞の17頭特徴量、公式T-10予測を一切変更しない。

- V1：F3の馬ごと3着以内確率を和3へ投影し、条件付きベルヌーイ最大エントロピーで全3頭組合せを構築。
- **V2：3連複の実際の3頭組合せラベルに対して、V1の組合せ確率へ条件付きロジットの残差補正を学習。** 補正後は確率総和1と3頭集合制約を満たす。補正後の個別周辺確率はV1と**完全一致しない**ため、周辺確率保存と主張しない。
- 学習に使うのは**前走までの先行位置指標、当日事前確定の枠順、F3予測、市場単勝のレース前情報**のみ。結果・当日通過順位は教師ラベル以外に使用しない。

## 1. 実装

- `src/keiba_place_lab/trio_residual_v2.py`：任意の3頭集合の相互作用特徴量を作り、L2正則化条件付きロジットを最適化。全頭出走の3頭集合の確率はソフトマックスで規格化。
- **事前指定候補**：
  - `f3_raw`：V1そのまま。
  - `pair_strength`：有力馬同士の強度相互作用。
  - **`race_interactions`（主要候補）**：有力馬同士・過去の先行位置類似・枠順類似。
  - `market_hybrid`（探索的候補）**：主要候補＋単勝市場のPlackett–Luce同時確率との乖離。
- 全ての候補は固定L2正則化 `lambda=0.05`、係数範囲 `[-4,4]`。2024年は係数・特徴量の選択にも使わない。
- `scripts/research_trio_v2_walkforward.py`：2010–2024全JRA出走馬から出典を監査、2023年でfit、2024年は不変評価。2026年の追加出力は**異なるF3学習設定への感度分析（Shadow）**として明示。
- `src/keiba_place_lab/trio_operational_gate.py`：公式/出典付きの3連複全組合せオッズが揃わない、不一致・別時刻・3分超経過なら計算拒否。実運用に必要なエビデンス未充足は必ず`NO_BET`。ユーザーの明示操作がない自動投票は実装していない。

## 2. 再現可能な実データ試験

データはリポジトリ固定の2010–2024年JRA出走馬707,067件、該当する原本Kaggle V1 `keiba_results.csv` ・ `keiba_races.csv`をSHAと馬ID×レースIDで照合。707,067全件の騎手・結果結合が成功。現行F3の2023/2024年OOF（XGB **120本の履歴代理モデル**）を使用。

- 2023年：完全な馬別OOF・全出走・上位3頭の着順が確定した1,355レースでV2の3種類の係数を学習。
- 2024年：同条件の**1,336レース、106開催日**を独立評価。レース単位の損失のペア差を日付クラスタ2,500回bootstrap。
- 2024年V1 joint log lossは既存の `4.4964765097602095` と誤差2e-8未満で一致した場合のみ続行。予測確率・実結果の対応違いを排除。
- 原始OOF 5,731レースのうち、全頭F3と実際の上位3頭が厳格に揃う2,691レースのみ利用（**3,040レース除外**）。全JRAへの性能一般化は主張しない。

主要候補V2の対V1平均Joint log loss改善：
`+0.0013858175`、日付クラスタ95%ブートストラップ信頼区間
**`[-0.0006052064, +0.0034644751]`**、Brier改善`+0.0001417893`。

**主要候補の合格条件：平均loss改善の95%区間下限 > 0、かつBrier悪化なし。2024年の結果は下限が負であり、不合格。**

探索的market_hybridの平均改善は`+0.0026410057`だが、同じ2024年での95%区間`[-0.0004307370, +0.0056388332]`。**3候補とも2024年で統計的に確実な改善とは言えない**。最大の点推定を見て後付け選択・昇格しない。

### 距離・芝ダートでのばらつき

主要候補のJoint log loss改善は、芝1600m以下`+0.002190`、芝1601–2399m`+0.002568`、芝2400m以上`-0.000313`。ダート1600m以下`-0.001168`、ダート1601–2399m`+0.002508`、ダート2400m以上`+0.005066`（ただしダート長距離は14レースで不十分）。一様な改善は確認できない。

## 4. 実運用の未解決ゲート

1. **同一の凍結済み800/400 F3アンサンブルの、対象時点前に学習した独立2025年または2026年の全馬OOF**を構築し、V2係数の転用を検証。
2. 事前予測時刻を保存した**発走10分前の実市場オッズ**に基づく適合性評価。過去の最終単勝オッズは直前オッズと同じではない。
3. 同じ時刻の全`nC3`の3連複投票法オッズが揃った、再現可能で権利上利用可能なソース。単勝からのPL値は代替不可。
4. 3連複の実払戻、取消・除外・同着・投票締切・オッズ変動などの扱い。JRAの3連複設定払戻率は75%（[JRA公式](https://www.jra.go.jp/kouza/baken/index.html)）。
5. 独立データで、期待収益・払戻後キャッシュフロー・元本全損確率を分析。単一レースで黒字保証は不可能。
6. 日付・レース・オッズ欠損・供給遅延・学習期間混入へのfail-closed監査。手動承認なしの自動投票は不可。

**現在、6ゲートの証拠が全て揃っていないため `NO_BET`。V1/V2のどちらも実運用向けの無監督投票には採用しない。**
